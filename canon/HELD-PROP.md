# Held-prop prompt contract

When the reference holds something, or a canon quality exists only if a hand and an object meet, the prompt does not say "holding" and stop. A1's required staging clause `hands empty and open` is replaced. W3 already licenses the word `holding` as a framing clause, and that word alone does not place the object.

The prompt must say all of these, in positive language:

1. Which hand closes on the object.
2. What that hand grips.
3. Where the object's inner face meets the body. A prop that only stands beside the figure is not held.
4. Where the free hand is, and that it is empty.
5. `feet planted and visible`.
6. On any view that is not the front, the head stays aligned with the body.

A side view is required before a held prop is accepted. A front plate hides the gap between the object and the chest.

`no held objects` stays the clause for a subject whose hands are empty. It is not the clause for a subject whose sprite carries something.
